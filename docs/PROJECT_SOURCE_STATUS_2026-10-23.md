# Источники и статус Audience Choice · 23.10.2026

**Тип:** актуальная карта источников. **Не новый MASTER**, не изменение сценарных решений и не разрешение на деплой.

## 1. Правило, принятое владельцем 18 октября

- Гость указывает свою команду из пяти Team 01–05.
- Голосует **ровно за одну из четырёх других команд**.
- **Самоголосование запрещено** и исключено из UI; SQL/RPC отвергает совпадение `own_team = team_no`.
- Своя команда заявляется самим гостем, не проверяется по личным документам или составу команд.
- `guest_id` ограничивает повторный голос в пределах конкретного браузера и опроса. Не утверждать, что система гарантирует один голос **на человека** между устройствами.
- Бумажный бюллетень должен иметь **два поля**: `MY TEAM` и `MY VOTE`; одинаковые номера означают недействительный голос.
- При полном/частичном отказе онлайн-тур аннулируется и проводится полный новый бумажный тур, без суммирования голосов.
- Победитель определяется голосами зала, не ChatGPT. Правило равенства первых мест — совместный Audience Choice Award; физические призы согласуются отдельно.

**Реализация уже есть в `main`**: `audience-choice-flow.mjs`, `audience-vote.html`,
`audience-choice.sql` / `supabase/migrations/20261017225915_audience_choice_global_startup_accelerator.sql`,
`tests/audience-choice-flow.test.mjs`, `tests/audience-choice-smoke.sql`.
Не добавлять альтернативный второй вариант голосования.

## 4. Правило дальнейшей синхронизации

1. Изменять каноническое правило только по **прямому решению владельца**.
2. Новое решение записывать в Decision Log и сценарный MASTER, а в GitHub оставлять ссылку на решение; историю не удалять.
3. Новый проектный MASTER **замещает**, а не дополняет старый после явного прикрепления в ChatGPT Project. Коммит в GitHub не заменяет прикреплённые Project-файлы.
4. Для кода использовать отдельную ветку / PR, проводить тесты. **Никакого merge/deploy, SQL-миграции, очистки голосов или смены current-сессии по одной лишь редактуре документов**.

6. Не утверждать статус мобильной репетиции, официальное время, имена команд, призы или договор как подтверждённые без соответствующего первичного доказательства.
