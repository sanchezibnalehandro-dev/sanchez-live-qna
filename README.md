# altera-qna-live

Live Q&A-инструмент для мероприятий: гости задают вопросы спикеру по QR/ссылке, вопросы собираются в живую ленту, модератор и администратор управляют потоком в отдельных окнах.

## Что умеет проект

- гостевая страница для отправки вопросов
- лента вопросов по текущему активному спикеру
- `+1` для актуальных вопросов
- отдельное окно модератора
- отдельная основная админка
- переключение активного спикера
- открытие / закрытие приёма вопросов
- включение / выключение премодерации
- Supabase как backend
- деплой на Vercel

---

## Каноническая схема работы

Основной рабочий контур сейчас такой:

1. пользователь открывает корневую ссылку проекта
2. корень ведёт на страницу логина
3. после пароля открывается основная админка
4. из основной админки открываются:
   - гостевое окно
   - окно модератора

Канонические страницы:

- `/` → редирект на `login.html?room=altera-forum`
- `login.html?room=altera-forum`
- `admin-main.html?room=altera-forum`
- `ask.html?room=altera-forum`
- `mod.html?room=altera-forum`

---

## Основные страницы

### `login.html`
Страница входа с паролем.  
После успешного входа отправляет в `admin-main.html`.

### `admin-main.html`
Главная админка проекта.

Что в ней есть:
- управление состоянием комнаты
- открытие / закрытие приёма вопросов
- включение / выключение премодерации
- редактор активного спикера
- список спикеров
- лента последних вопросов
- быстрый запуск guest / moderator

### `ask.html`
Гостевая страница для отправки вопроса текущему спикеру.

### `mod.html`
Окно модератора для работы с вопросами.

## Backend / база данных

Проект использует Supabase.

Основные таблицы:

- `qna_rooms`
- `qna_speakers`
- `qna_questions`
- `qna_question_votes`

SQL-файлы в репозитории:

- `schema.sql` — схема таблиц и триггеров
- `RLS.sql` — политики доступа
- `demo-data.sql` — демо-данные для комнаты `altera-forum`

---

## Конфиг Supabase

Используются файлы:

- `supabase-qna-config.js`
- `supabase-qna-config.example.js`

`supabase-qna-config.js` нужен для рабочего подключения к проекту Supabase.

## Важное замечание по доступу

Текущий парольный вход — это **лёгкий gate для MVP**, а не полноценная защищённая серверная авторизация.

Если проект пойдёт в реальную эксплуатацию на более серьёзном уровне, следующий шаг — усилить доступ и сделать более правильную схему авторизации.

## Для чего этот проект

Проект собран как практический live-инструмент для мероприятий, панельных дискуссий и публичных сессий, где важно:

- быстро собирать вопросы от гостей
- не терять популярные темы
- давать модератору удобный рабочий контур
- держать администратору контроль над всей логикой в одном окне
